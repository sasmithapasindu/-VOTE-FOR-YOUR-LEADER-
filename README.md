# 🗳️ Vote for Your Leader

A simple Python-based voting system where users can vote for their preferred leader multiple times. The program counts the votes, determines the winner, handles ties, and displays the results using a bar chart.

## ✨ Features

* 👥 Multiple leaders
* 🔢 Number-based leader selection
* 🗳️ Multiple voting rounds
* ✅ Validates voting choices
* 📊 Counts votes automatically
* 🏆 Determines the winner
* 🤝 Detects ties between leaders
* 📈 Displays voting results as a bar chart

## 📦 Installation

Make sure Python is installed, then install Matplotlib:

```bash
-r requirements.txt
```

## 🚀 How to Run

Run the Python file from your terminal:

```bash
python voting.py
```

The program will display the available leaders:

```text
=== VOTE FOR YOUR LEADER ===
[1] Saman
[2] Kamal
[3] Supun
[4] Amal
```

Enter the number of the leader you want to vote for.

After voting, you can choose whether to vote again:

```text
Do you want to vote again? (yes/no)
```

When you select `no`, the program displays the final results.

## 📊 Results

The program shows the number of votes received by each leader and determines the winner.

It also generates a **bar chart** using Matplotlib to visually display the vote results.
